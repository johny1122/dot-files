# Plan files

- When writing a plan to a file, always give it a descriptive kebab-case name based on the plan's subject (e.g. `add-oauth-login-plan.md`). Never use generic names like `plan.md`.
- Save plan files in `<cwd>/.claude/plans/`, not the repo root or elsewhere.
